P091 Verifiable confidential computing via network commitments

Can a full loop - the prover's network hardware committing to its traffic, then a neutral site verifying it - give both confidentiality and later proof, demonstrated end to end on a real workload?

Architectures where network hardware commits to traffic so a neutral site can later verify confidential workloads.

Terms: commitment: a tamper-evident cryptographic 'fingerprint' of data, published so the data cannot later be changed unnoticed. gateway: the network device that records such commitments at the site boundary.

Status

Started One component measured: hashing every frame on one 400GbE link, on a 64-thread server CPU and on a BlueField-3 network card, to build a log for later checking. No commitment protocol or neutral-site verification has been built, and nothing has been demonstrated end to end on a real workload. The design for the full loop is in Harack et al. (2025), which says no existing system does this and that cost, difficulty and time at scale are unanswered.
